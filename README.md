# Priciest Printing

## GitHub Codespaces

On creation, the Codespace installs the npm dependencies. Each time it starts,
it builds the frontend and serves it on forwarded port 4173. Open the port from
the Ports tab if it does not open automatically.

Run `npm run build` after changing frontend files to update the served site.
The server log is available at `/tmp/priciest-printing-server.log`.
